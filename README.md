# Flowda developer resources

Flowda gives LLM apps and agents live web data. This repository is a developer-facing resource hub for guides, tutorials, code examples, comparisons, use cases, and reference material.

- Official website: [https://flowda.ai/](https://flowda.ai/)
- Developer docs: [https://docs.flowda.ai/](https://docs.flowda.ai/)
- API reference: [https://docs.flowda.ai/docs/api/flowda-developer-api](https://docs.flowda.ai/docs/api/flowda-developer-api)
- Build with AI: [https://docs.flowda.ai/docs/agent-tools/overview](https://docs.flowda.ai/docs/agent-tools/overview)

## What this repository is

This is a Markdown-based developer resource repository. It is not a standalone blog site, GitHub Pages site, or Git Site integration. Content here is meant to be read from GitHub.

## What Flowda does

Flowda provides one API for LLM applications and agents to:

- search the live web;
- read public pages as Markdown or HTML;
- extract structured records from supported pages;
- map a site's URLs;
- monitor pages and receive change events.
